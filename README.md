# 영단어 (수능 영단어 PWA)

폰 홈 화면에 설치해서 쓰는 수능 영단어장. 켜면 바로 단어 카드, 끝없이 나옴.

## 파일
- `index.html` 앱 전체 (화면 + 출제 로직)
- `words.json` 단어 데이터 — 한 줄에 한 단어:
  - `w` 단어
  - `m` 뜻 목록. 앞에 `*` 붙은 뜻이 수능 빈출 (노란 하이라이트)
  - `r` 같이 알아둘 것: `[종류, 표현, 뜻]` — 종류는 혼동 / 유의 / 반의 / 파생 / 어법
  - `e` 예문, `k` 해석
- `sw.js` 오프라인 캐시, `manifest.webmanifest` 홈 화면 앱 설정, `icons/` 아이콘

## 내 단어 추가 (앱 안에서)
검색에서 없는 영어 단어를 치면 맨 위에 `+ 단어` 가 뜸 → 뜻(쉼표로 여러 개, 첫 번째가 주요 뜻), 예문(선택) 입력 → 추가. 기본 단어와 같이 섞여 나옴. 검색에서 펼치면 삭제 가능.

## 단어 추가 (파일)
`words.json`에 같은 형식으로 줄을 추가하고 다시 올리면 됨. 새 단어는 섞인 순서로 나옴.

## 배포 (GitHub Pages, 무료)
1. github.com에서 새 저장소 만들기 (예: `vocab`)
2. Add file → Upload files 로 이 폴더 안의 파일 전부 올리기 (icons 폴더 포함)
3. Settings → Pages → Branch를 `main` / `(root)` 로 저장
4. 1~2분 뒤 `https://<아이디>.github.io/vocab/` 로 접속

## 폰에 설치
- 아이폰: Safari로 주소 열기 → 공유 → 홈 화면에 추가
- 안드로이드: Chrome으로 열기 → 메뉴 → 앱 설치(홈 화면에 추가)

## 기록
학습 기록은 폰 안(브라우저 저장소)에 저장됨. 홈 화면에 설치해서 쓰면 유지되고, 다른 기기와는 공유되지 않음.
